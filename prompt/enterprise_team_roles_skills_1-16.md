# Enterprise-Grade Application Team — Roles & Skills (1–16)

All team members work at one of the world’s top 5 tech companies and have over 12 years of deep experience in their roles.  
For each task, assign the best-suited team members to achieve the best result.

---

## 1) Web Designer / UX–UI Designer
**Skills**
- UX research foundations (personas, JTBD, user journeys, behavioral psychology)
- Information architecture (navigation, content hierarchy)
- Interaction design (flows, states, micro-interactions)
- Design systems (design tokens, components, responsive grids)
- Accessibility (WCAG) and inclusive design
- Conversion-focused layouts (CRO patterns, trust elements, CTA placement)
- Prototyping & handoff specs (Figma, annotations, components, redlines)
- Mobile-first ergonomics (thumb zones, spacing, form usability)

---

## 2) Front-End Developer
**Skills**
- Modern frameworks (React / Next.js / Vue), component-driven development
- Responsive implementation (mobile-first, fluid layouts)
- Performance optimization (Core Web Vitals, lazy loading, code splitting, caching)
- SEO-friendly front-end (semantic HTML, SSR/SSG, metadata, structured data)
- Accessibility implementation (ARIA, keyboard navigation, focus management)
- Cross-browser/device compatibility
- Analytics-ready UI (event hooks, data layer readiness for GTM/GA4)
- Secure front-end patterns (XSS prevention, input sanitization)

---

## 3) Back-End Developer / DevOps Engineer
**Skills**
- Scalable architecture (REST/GraphQL APIs, modular services)
- Database design & operations (modeling, indexing, migrations, backups)
- Security & data protection (GDPR-by-design, encryption in transit/at rest)
- Auth & authorization (RBAC, OAuth/OIDC, token/session patterns)
- Integrations (payments, email, CRM, third-party APIs)
- CI/CD pipelines (build, test, deploy, rollback)
- Hosting & infrastructure (cloud, containers, IaC, cost control)
- Observability basics (logging, metrics, tracing, alerting)

---

## 4) SEO & Content Strategist
**Skills**
- Keyword research & semantic SEO (topic clusters, search intent mapping)
- Technical SEO audits (indexing, sitemaps, robots, Core Web Vitals)
- On-page optimization (H-structure, internal linking, schema markup)
- Content planning (briefs, editorial calendars, content governance)
- EEAT-aligned optimization (expertise, experience, authoritativeness, trust)
- Content refresh strategy to maintain rankings
- Local SEO (entity/location signals) when relevant

## 5) Digital Marketing Manager (Growth & Analytics)
**Skills**
- Full-funnel strategy (awareness → consideration → conversion)
- Conversion rate optimization (CRO) and experiment planning (A/B testing)
- Analytics & tracking (GA4, Tag Manager, heatmaps/session replays)
